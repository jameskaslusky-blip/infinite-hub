About the Infinite Hub ∞

A giant, single-file web app demo built to show how much can fit into one website.

What's inside?

This is more than a landing page. It is a small web application with multiple sections, responsive layouts, interactive tools, mini-games, a story archive, notes, tasks, and browser-based saving.

✓10 navigable sections
✓Responsive desktop and mobile layout
✓Dark and light themes
✓Tasks, notes, quotes, playlist, lore, and checklist persistence
✓Quiz, calculator, word counter, timer, randomizers
✓Exportable data and keyboard shortcuts

Important reality check

This demo runs in your browser. It does not have a server, user accounts, online sync, real-time multiplayer, or a public URL by itself. The information you add is stored in this browser using local storage. Export your data before clearing browser data or switching devices.

The Bodacia case file

Bodacia is a skyscraper city where crimes hide behind clouds of gas. Jar Jar Binks discovers artificial bodaciousness and sells it as the real thing in a tortilla throw blanket. Bodacious Inc. catches the lie and hires Sheriff Ratey the Math Cat. Crime falls by 80%, but a tip sends Ratey to a hideout in Buffdogland, where he falls into a chamber trap. The case is not over.

This summary follows the Bodacia story details provided for this project. Add more lore in the notebook.
